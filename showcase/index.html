    WINDOWS ZIP PARITY

    为什么 macOS 也需要一款「Windows 级」压缩软件？

    针对 macOS 原生归档工具高频痛点逐一工程级重塑

    🗂️

    像资源管理器一样「包内直览与原地增删改」

    无需全量解压即可浏览目录树、嵌套压缩包钻取回退、空格 Quick Look 预览、直接拖出到访达、拖入文件进 ZIP、查看/编辑归档注释，未改动文件零重压缩。

    🧹

    自动删除 .DS_Store 等垃圾文件

    打包、包内追加与解压时默认自动剔除 .DS_Store、__MACOSX 与 ._*，发给 Windows/Linux 同事干干净净。

    🧠

    Smart 智能解压 & 默认文件关联

    单一根目录直接释放不套娃，多文件自动建同名文件夹；设置内可一键把 ZIP/RAR/7z/TAR 设为 BoltZip 默认打开并换上 17 套分格式定制图标。

    🀄

    GBK / Shift-JIS 乱码自愈

    自动识别 Windows 工具打包的无 UTF-8 标记文件名（GB18030 / Big5 / Shift-JIS / EUC-KR）。

    🔐

    RAR/RAR5 + WinZip AE-2 + 多核并行

    完整支持 RAR/RAR5 浏览解压、WinZip AE-2 AES-256 加密互通与安全符号链接，并采用 64 MB+ 真流式引擎与多核并发加速。

    ⚡

    访达右键「Bolt ›」独立悬浮进度窗 & .dmg 安装镜像

    提供 Retina 拖拽安装 .dmg 镜像；原生 FinderSync 菜单支持智能解压、自定义解压与多选分别压缩为 ZIP，附带 boltzip CLI（含 add/rm/mv/--json）。

    💻

    双轨版本：v1.0.5 Apple Silicon 与 v0.9.3 Universal

    v1.0.5 面向 Apple Silicon（arm64）+ macOS 26+ 深度打造，内置 GitHub Releases 自动更新检查；Intel Mac 或 macOS 12–15 用户可随时选择内置静态 libarchive 3.7.7 的 v0.9.3 Universal 兼容版。

    🪟

    macOS 26+ 原生三层液态玻璃 & 统一背景体系

    工作台、设置、压缩向导全面采用原生 Liquid Glass，支持配色预设、透明度与模糊深度调节；v0.9.3 在 macOS 12–15 自动切换纯净原生界面。

    核心算法均静态编译自成熟开源 C 实现，可审计、无第三方动态库依赖

    从 GitHub 克隆并构建 BoltZip

    main 分支专攻 Apple Silicon (macOS 26+)，legacy/macos-12 分支保留 macOS 12–26 Universal 构建脚本

    1. 克隆并打包 .app 与 .dmg 
    git clone https://github.com/hwang8859-1/BoltZip.git
cd BoltZip
./Scripts/build_app.sh
open dist/BoltZip-1.0.5-macOS-arm64.dmg
    2. 切换兼容分支或运行测试 
    swift test
# Intel / macOS 12-15 兼容线:
git checkout legacy/macos-12
./Scripts/build_app.sh
    3. 使用 boltzip CLI 
    swift run -c release boltzip a release.zip ./src --algo zstd --aes256 --password Secret
swift run -c release boltzip t release.zip --password Secret
swift run -c release boltzip bench
