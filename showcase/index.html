    WINDOWS ZIP PARITY

    为什么 macOS 也需要一款「Windows 级」压缩软件？

    针对 macOS 原生归档工具高频痛点逐一工程级重塑

    🗂️

    像资源管理器一样「包内直览与原地增删改」

    无需全量解压即可浏览目录树、空格键调用 Quick Look 预览、直接拖入新文件进 ZIP、重命名、删除或单独导出选中项——未改动文件零重压缩。

    🧠

    Smart 智能解压

    自动判断包内结构：单一根目录直接释放不套娃；多文件散装包自动建立同名子目录。

    🀄

    GBK / Shift-JIS 乱码自愈

    自动识别 Windows 工具打包的无 UTF-8 标记文件名（GB18030 / Big5 / Shift-JIS / EUC-KR）。

    🔐

    WinZip AE-2 AES-256

    PBKDF2-HMAC-SHA1 + AES-256-CTR + 10B HMAC-SHA1，与 Windows 7-Zip / WinZip 密码互通。

    🪟

    液态玻璃与模块化定制

    支持窗口背景半透明开关与透明度微调，欢迎页各卡片、访达提示条、状态栏均支持独立隐藏。

    ⚡

    访达右键一级目录「Bolt ›」 & Swift 6 CLI

    通过原生 FinderSync 扩展把「智能解压 / 压缩 ZIP / TAR.ZST / 7z / 加密打包」放到右键第一层；并附带 boltzip 命令行工具与 AGENTS.md 开发者指引。

    OPEN-SOURCE CODEC CORE

    全栈开源压缩算法引擎 · 场景对比

    核心算法均静态编译自成熟开源 C 实现，可审计、无第三方动态库依赖

    选择负载场景（参考模型对比，客户端内支持对当前 Mac 实时跑分）：
    zlib (zlib License) Zstandard (BSD-3-Clause) XZ Utils / liblzma (0BSD) bzip2 (bzip2 License) LZ4 (BSD-2-Clause) libarchive (BSD-2-Clause)
    OPEN SOURCE QUICKSTART

    从 GitHub 克隆并构建 BoltZip

    仓库提供完整的 SwiftPM 工程、打包脚本以及面向开发者的 AGENTS.md

    1. 克隆并打包 BoltZip.app 
    git clone https://github.com/hwang8859-1/BoltZip.git
cd BoltZip
./Scripts/build_app.sh
open dist/BoltZip.app
    2. 运行全套单元测试 
    swift test
    3. 使用 boltzip CLI 
    swift run -c release boltzip a release.zip ./src --algo zstd --aes256 --password Secret
swift run -c release boltzip t release.zip --password Secret
swift run -c release boltzip bench
