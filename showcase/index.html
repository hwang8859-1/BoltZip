    WINDOWS ZIP PARITY

    为什么 macOS 也需要一款「Windows 级」压缩软件？

    针对 macOS 原生归档工具的 6 大高频痛点，逐一工程级重塑

    🗂️

    像资源管理器一样「包内直览与原地增删改」

    无需把几 GB 的压缩包全部解压到硬盘，直接浏览树形目录、双击调用 macOS Quick Look 预览图片/PDF/代码，还能像 Windows 7-Zip/WinZip 一样直接拖入新文件、重命名或删除条目——未改动文件零重新压缩。

    🧠

    Smart 智能解压

    自动判断包内结构：单一根目录直接平铺释放，避免出现 项目/项目/ 套娃；多文件散装包自动建立同名子目录，保持桌面整洁。

    🀄

    GBK / CP936 乱码终结者

    自动识别 Windows 资源管理器或旧版压缩工具打包的无 UTF-8 标记文件名（支持 GB18030、Big5、Shift-JIS、EUC-KR），再也不见满屏乱码。

    🔐

    WinZip AE-2 AES-256 加密

    采用 PBKDF2-HMAC-SHA1 + AES-256-CTR + 10 字节 HMAC-SHA1 认证标签，同时兼容传统 ZipCrypto 解密，发给 Windows 同事用 7-Zip/Bandizip 直接输入密码打开。

    🧩

    分卷压缩与 Mac 垃圾净化

    支持自定义体积切分 .z01 / .z02 / .zip 分卷方便微信/网盘传输；默认自动剔除 .DS_Store、__MACOSX 与 ._* 资源分叉文件。

    ⚡

    访达右键快捷菜单 & Swift 6 原生命令行

    应用内置一键安装 macOS 访达快捷操作（Services），右键文件即可「使用 BoltZip 压缩」或「智能解压到当前位置」；同时附带极客 CLI 工具 boltzip 供终端与自动化脚本调用。

    OPEN-SOURCE CODEC CORE

    全栈开源压缩算法引擎 · 场景性能对比

    所有核心算法均静态编译自经过时间检验的开源 C 实现，安全透明、可审计、无专有闭源黑盒

    选择典型负载场景（参考模型对比，客户端内支持对本机真实文件一键跑分）：

    BUILD & RUN ON MACOS 27.3

    立即编译运行 BoltZip.app 与 CLI

    项目已就绪于本地 ~/Codes/BoltZip，包含完整单元测试、原生桌面应用与命令行工具

    1. 构建 BoltZip.app 原生应用包 
    cd /Users/xuyang/Codes/BoltZip
./Scripts/build_app.sh
open dist/BoltZip.app
    2. 运行全套开源算法与加密测试 
    cd /Users/xuyang/Codes/BoltZip
swift test
    3. 使用 boltzip CLI 高效压缩与校验 
    swift run boltzip a release.zip ./src --algo zstd --aes256 --password MySecret
swift run boltzip t release.zip --password MySecret
swift run boltzip bench
